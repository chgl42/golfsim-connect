# Architecture decision records

Decisions that shape the code, with the reasons behind them, so they aren't re-argued or undone by
accident. The overview of the code is in [architecture.md](../architecture.md).

A new record starts from [template.md](template.md), takes the next number and is added to this
list in the same pull request as the change it describes. Numbers are never reused; a record that
no longer holds is marked *Superseded by ADR-NNN* or *Deprecated*, not deleted.
